# 風笺 · WindLetter Desktop 使用说明

适用版本：`0.1.0`

## 1. 安装

推荐双击 `WindLetter-0.1.0.exe`，按提示选择安装目录、开始菜单和桌面
快捷方式。也可以使用 `WindLetter-0.1.0.msi`。

当前 Demo 安装包尚未进行代码签名，Windows 可能显示“未知发布者”或
SmartScreen 提示。只应使用从项目维护者获得且校验值一致的安装包。
应用自带 Java 运行时，无需另装 JDK 或 JavaFX。

## 2. 第一次启动与保险库

第一次启动需要创建保险库密码：

- 长度为 8–256 个 Unicode 字符；
- 密码框右侧小眼睛可临时显示或隐藏输入；
- 私钥、身份和联系人保存在
  `%APPDATA%\WindLetter\vault.wlv`；
- Vault 使用 Argon2id 派生密钥，并使用 AES-256-GCM 认证加密；
- 密码遗失后没有后门、找回密码或服务端恢复。

请尽快在“保险库”页创建完整备份。备份本身仍是加密 Vault，但密码和
备份同时丢失时，原有私钥与历史消息解密能力将永久丢失。

## 3. 我的身份

在“我的身份”页可以：

1. 生成 X25519 身份或 X25519 + ML-KEM-768 混合身份；
2. 设置不可变的 `display name`，它是当前 Demo 中给联系人展示和识别
   该密码学身份的名称；
3. 编辑仅供本机管理的备注 `note`；
4. 选择默认身份、导出完整加密备份或删除身份；
5. 复制公开身份的标准 Base64 PEM 或風铭 WindBase 文本。

`display name` 在身份生成后不能修改。消息协议本身不携带这个名称；
收件人看到的名称来自事先导入并匹配到的公开身份。

公开身份文本格式：

```text
-----BEGIN WINDLETTER PUBLIC IDENTITY-----
<公开身份 JSON 的标准 Base64，按 64 字符换行>
-----END WINDLETTER PUBLIC IDENTITY-----
```

```text
-----風铭 起-----
<WindBase 编码正文>
-----風铭 凪-----
```

只复制公开身份不会泄露私钥。

## 4. 联系人

在“联系人”页粘贴标准 PEM、風铭文本或兼容的公开身份 JSON，然后导入。
导入后可修改本地备注，但不能改变对方身份的 `display name` 或密钥。

发送签名消息前，应通过可信渠道核对联系人公开身份。仅仅成功导入一段
文本不等于确认它确实属于某个人。

## 5. 发送消息

1. 选择文本输入或文件 payload；
2. 选择一个或多个收件人；
3. 选择模式：
   - `public`：允许使用发送者加密身份；
   - `obfuscation`：隐藏发送者加密身份线索；
4. 选择 `X25519` 或 `X25519ML-KEM-768`；
5. 选择 signed 或 unsigned；
6. 选择输出格式：
   - 标准 Base64 PEM；
   - 風笺 WindBase 文本；
   - binary 文件；
7. 生成后复制文本或保存文件。

应用会拒绝与收件人密钥能力不兼容的组合。signed 消息使用所选本地身份
签名；unsigned 消息不能向收件人证明发送者身份。

## 6. 接收消息

1. 粘贴标准 Base64 PEM 或風笺文本，或者导入 binary 文件；
2. 选择用于尝试解密的本地身份；
3. 点击处理消息；
4. 只有核心严格解析、路由、解密、binding 和验签全部返回成功后，
   应用才会展示 payload。

结果会明确区分：

- 已签名且已验证：显示匹配联系人和认证状态；
- 未签名：payload 已恢复，但发送者无法认证；
- 不是发给当前身份；
- 消息无效、被截断、被篡改或格式不受支持。

为避免形成攻击 oracle，界面不会暴露底层密码错误、密钥匹配细节或内部
异常。保存恢复文件时，应用会根据消息 MIME 类型建议 `.pdf`、`.png`、
`.json` 等后缀；无法可靠识别时才使用 `.bin`。

复制恢复明文后，如果剪贴板仍是应用复制的内容，应用会在 60 秒后清除；
锁定、关闭接收页或处理下一条消息也会提前清除。用户后来复制的其他内容
不会被覆盖。

## 7. 锁定、备份与卸载

- 离开电脑前应手动锁定；应用也会按当前设置自动锁定；
- 完整备份包含私钥，必须像原 Vault 一样保护；
- 公开身份导出不包含私钥，不能用于恢复解密能力；
- 卸载应用会删除程序文件，但不会主动删除
  `%APPDATA%\WindLetter\vault.wlv`；
- 重装或升级前仍应先备份 Vault，避免磁盘、账户或人工操作造成数据丢失。

如果确实要销毁本机身份，应先在应用内删除并保存 Vault，再评估备份、
文件历史、云同步和 SSD 删除残留。普通文件删除不承诺物理不可恢复。

## 8. 当前 Demo 边界

- Windows x64；
- 安装包尚未代码签名；
- 尚未在独立全新 Windows 虚拟机做 clean-machine 验收；
- 尚无第二个发布版本，因此跨版本升级保留 Vault 的闭环尚未实测；
- 核心依赖仍通过精确 Git 提交校验和隔离 Maven 仓库固定，而非公开的
  不可变 Maven release。
